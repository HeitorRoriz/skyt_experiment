%% ---------- ABSTRACT ----------
\begin{abstract}
Existing code-generation benchmarks score a single sample against a behavioral oracle. They do not measure how much the \emph{structure} of correct code varies when the same prompt is regenerated. We propose a \textbf{structural repeatability protocol}: $N$ independent generations, a property-based structural distance, and population-level reports based on pairwise U-statistics and certified modal mass. The protocol separates \emph{measurement} (how scattered are the outputs?) from \emph{policy} (which verified form should count as the canon?). On a locked corpus of commercial-LLM generations we report a corrected behavioral--structural gap and the effect of a post-generation canonicalizer (\skyt{}); an external-task arm on HumanEval is in progress. % W1/W3: replace this sentence with numbers after recompute under the Methods freeze.
\end{abstract}

\keywords{LLM code generation, structural repeatability, U-statistics, canonicalization, HumanEval, software measurement}

\section{Introduction}
\label{sec:intro}
%% W2: ruler-first story. Benchmarks score one output; we score dispersion across N.
%% Do not lead with the 66pp figure.

Correctness benchmarks for LLM code generation---HumanEval~\cite{chen2021evaluating}, MBPP~\cite{austin2021program}, SWE-bench~\cite{jimenez2024swebench}---ask whether \emph{a} generated artifact passes tests. Production pipelines, however, regenerate: CI re-runs generators, agents retry, and independent developers issue the same prompt. Behavioral oracles cannot tell two passing regenerations apart, yet the artifacts can differ in structure~\cite{ouyang2023llm}.

This paper's primary contribution is a \textbf{benchmark-agnostic overlay} that measures that structural scatter (\textbf{C1}). We then show that the choice of reference form (the \emph{canon}) is a policy, not a measurement, and compare first-compliant anchoring to a Certified Consensus Canon (\textbf{C2}). We apply the protocol to an existing contract corpus (\textbf{C3}, Results~A) and to HumanEval (\textbf{C3}, Results~B; W3). Finally we rescore a post-generation repair tool, \skyt{}, under the same honest metrics (\textbf{C4}).

\paragraph{Not in this paper.} Generation-by-construction (``Code DNA'') is a separate vision paper. We do not claim MISRA~C or NASA Power-of-10 compliance for any contract.

\section{The Structural Repeatability Protocol}
\label{sec:protocol}
%% W1: full Methods. Inputs, N, distance, U-statistics, modal mass,
%% Certified Consensus Canon, CV-at-s=10, CI rules.

\subsection{Inputs and regenerations}
A \emph{task} supplies a prompt, a behavioral oracle (unit tests), and optional static constraints (a \emph{contract}). For each experimental cell we draw $N$ independent generations (corpus: $N{=}20$).

\subsection{Structural sameness}
Two generations are structurally identical when a vector of 14 foundational properties has distance $0$ (including $\alpha$-renaming where the contract allows). Headline exact-match rates are therefore \emph{weight-independent}: distance $0$ requires all properties to match. Mean distances are descriptive support only.

\subsection{Population measures (not policies)}
\label{sec:measures}
\begin{enumerate}
  \item \textbf{End-to-end pairwise exact-match U-statistic:} probability that two independent draws both certify and match at distance $0$. Conditional-among-valid pairwise match is secondary.
  \item \textbf{Certified modal mass:} size of the largest certified exact-match class divided by $N$ (denominator is all generations, not only passers).
  \item \textbf{Pairwise distance U-statistic} (secondary).
\end{enumerate}
Pairs within a config are dependent. Inference aggregates \emph{one score per contract} and uses a \textbf{cluster bootstrap}. Do not treat $C(N,2)$ pairs as binomial trials. Do not put a Wilson interval on in-sample modal share.

\subsection{Canon policy (separate from measurement)}
\label{sec:canon-policy}
\textbf{Certified Consensus Canon:} among generations that pass the oracle \emph{and} contract compliance, take the modal exact form; break ties by medoid, then a deterministic lexicographic rule.

\textbf{Policy evaluation:} repeated balanced cross-validation at operational batch size $s{=}10$ (U-statistic CV; large fixed-seed $B$), reporting held-out match, distance, and canon stability. Baselines: first-compliant vs Certified Consensus. Leave-one-out and temporal splits are sensitivity checks only. A Wilson interval is valid only for a \emph{frozen} canon scored on an independent batch.

\section{Threats to Validity}
\label{sec:threats}
%% From Gate 0 memo. Expand in W2.

\begin{itemize}
  \item \textbf{Oracle strength.} Some cells have weak tests (\eg{} \texttt{slugify}/GPT-4o at $T{=}0$). Certified rates inherit oracle quality.
  \item \textbf{Construct.} Distance-$0$ on 14 properties is not semantic equivalence of all possible programs.
  \item \textbf{Temperature 0.} Commercial APIs are not bit-deterministic at $T{=}0$.
  \item \textbf{Sample size.} $N{=}20$; $n{=}10$ is the operational CV batch and the HumanEval-pilot design.
  \item \textbf{Unsatisfiable strict contracts.} \texttt{binary\_search\_strict} had $0/20$ compliant in analyzed cells (literal-pattern constraints).
  \item \textbf{Missing cell.} \texttt{is\_prime\_strict}$\times$Claude never completed (5 configs).
  \item \textbf{Task selection.} Corpus A is author-designed; Corpus B (HumanEval) is the planned answer. SWE-bench is future work (multi-file; extractor does not transfer).
\end{itemize}
